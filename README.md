# Portfólio Pessoal — Mariana Paulino

Meu portfólio pessoal desenvolvido com HTML, CSS e JavaScript, criado para apresentar informações sobre mim, habilidades, projetos e contatos.

## Sobre o projeto

Este projeto foi desenvolvido com o objetivo de criar uma identidade visual e reunir informações acadêmicas, profissionais e projetos em uma única página.

## Funcionalidades

- Seção "Sobre mim"
- Apresentação de habilidades
- Área de projetos
- Links para redes sociais
- Navegação com rolagem suave
- Layout responsivo
- Interface minimalista

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Google Fonts
